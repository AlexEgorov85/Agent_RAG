# Design

## Context

Проверенное окружение (см. `scripts/test_hi_res.py`, лог `hi_res_test.log`):
`unstructured 0.27.36` + `unstructured-inference 1.6.17` на Python 3.11.9 —
`hi_res` работает без Poppler (рендеринг через pypdfium2), но **обязательно** требует
tesseract (найден и поставлен 5.4.0 через winget; языковые модели в `<project>/tessdata`,
включая `rus.traineddata` и `tessdata_fast`). Найти: `ocr_languages` → новый параметр `languages`.
Шум pdfminer («Cannot set non-stroke color») доброкачественный — глушится.

Целевой масштаб: 9 PDF (~168 МБ). Замер на 3 страницах 2015: 1143 элементов (~47 c/стр. на OCR).
Оценка полного прогона корпуса — 6–10 часов CPU → всё строится вокруг «запустил и ушёл».

## Goals / Non-Goals

**Goals:**
- Повторяемость: один и тот же PDF → один и тот же артефакт (стабильные `element_id`)
- Домашняя стойкость: resume, бэкап, реакция на менающийся источник
- Единый вход «сырья» для ingestion-модулей (`data/elements/`), Unstructured изолирован в этом модуле

**Non-Goals:**
- Дерево разделов / breadcrumbs (→ `structure_builder`)
- Чанки и вызовы LLM/VLM (→ `chunk_enricher`, `table_structurer`, `visual_describer`)
- Параллельный multi-процесс OCR внутри одного файла (сложность >> выигрыш; страницы последовательен)

## Decisions

1. **Батчи 20 страниц через `pages=[a, b]`**, один файл — за один проход.
   Альтернатива: парсить весь файл одним вызовом теряет resume-точки иRAM на огромных отчётах;
   параллельные воркеры на один PDF непредсказуемо потребляют память на OCR.
2. **`min_image_area = 200×200`** — лишние base64 одним пакетом до 2/3 объема JSON и захватывают
   фильтр VLM из спеки проекта. Логика в продаже: `image_b64 != null` есть буквально мелкие и значимые иммуноиконки.
3. **`doc_id` строго из имени файла** (`sber_{year}`); язык задания `languages=["rus","eng"]`.
   Альтернатива — грепнуть год из текста обложки, но там OCR-об tempting и метаданные ненадёжны.
4. **`element_id = doc_id:xxxxx`** (zero-padded 5-digit) — уникальные в пределах артефакта;
   попадут как строка в поле `element_ids` чан-контракта курса.
5. **`fast`-стратегия без OCR доступна лишь для превью** (не производит артефактов):
   в `fast` OCR/структура городов резко скушено, явно не тем же контракт качества.
6. **Курсовой код не затрагивается**: конфигурация — наследник курсовского `Settings` в `src/core/config.py`.
7. **`unstructured-inference>=1.6` в requirements.txt явно** — в unstructured 0.27 он ниже extras
   и отсутствует без него (`No module named 'unstructured_inference'` — уже поймали).

## Risks / Trade-offs

- [Oversized OCR cost — полный корпус ~6–10 часов] → батчи + resume: прерывание не теряет работу; `--fast-preview` для диагностики
- [Большие JSON (база64 картинок)] → фильтр 200×200; при необходимости — сохранять файлы картинок на диск вместо base64 ( Future: `image_path` средствами отдельного modification)
- [Ошибка page-координат из Unstructured] → валидация `page` ∈ [1..n_pages] при конвертации;喊着 лучше бы верх noticing прямо в артефакте
- [Встраивание 2021 отсутствует — на CLI и чанковых фильтрах НЕ обрабатывается] → это contracts следующих capabilities
- [dept `category_depth` несётся у Unstructured на сложных отчётах] → только here забота о сыре: парсер переносит значение; валидировать depth разрешено structure_builder'у
